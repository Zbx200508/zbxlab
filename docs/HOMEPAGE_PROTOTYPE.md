# ZBX Lab 首页原型

> 当前结论：首页先做成最小作品入口，不强行包装定位，不写长篇个人说明。

## 首页核心内容

```text
ZBX Lab
个人作品集
Projects / Resume / Contact
```

首页只展示三件事：

1. 项目卡片，点击跳转到对应项目详情页。
2. 简历入口，支持在线查看 HTML 简历，也支持单独下载。
3. 联系方式，展示 GitHub、邮箱、手机号。

## 页面结构

```text
顶部导航
↓
首页标题
↓
项目卡片
↓
简历入口
↓
联系方式
```

## 1. 顶部导航

```text
ZBX Lab    Projects    Resume    Contact
```

## 2. 首页标题

```text
ZBX Lab

个人作品集

Projects / Resume / Contact
```

## 3. 项目卡片

每个项目卡片整体可点击，鼠标悬停时显示选中效果。

当前项目：

```text
海信自动化报告工作台
雅迪 VOC 用户洞察看板
AI 原型与效率工具实验
```

## 4. 简历入口

```text
在线查看 HTML 简历
下载 PDF 简历
```

## 5. 联系方式

```text
GitHub
邮箱
手机号
```

## 暂时不放在首页的内容

- 简短个人说明。
- 大段能力标签。
- 方法论。
- 详细项目过程。
- Demo、PRD、GIF、截图。

这些内容后续放到项目详情页或简历页中。
