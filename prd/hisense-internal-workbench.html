面向海信品牌周报正式系统上线前的报告交付场景，内部工作台将报告配置、数据获取、指标计算、重点内容筛选、AI 洞察生成与 HTML 报告渲染集中处理，用于承接完整周报生成流程，并提升交付前报告制作效率。

01 人工周报流程

人工周报的耗时来源：数据处理、指标计算与内容核查

海信品牌周报并非单纯撰写总结，而是需要依次确认报告范围、拉取多平台数据、计算 SOV / SOE / NSR 等核心指标、筛选高互动与负面帖子，再基于结构化数据生成 AI 洞察并输出 HTML 报告。

品牌范围、统计周期、帖子样本或 AI 结论任一环节出现偏差，都会影响报告结论，后续需要重新取数、复核指标或调整洞察内容。

配置报告范围品牌、竞品、品线、周期、平台、关键词。
拉取多平台数据品牌声量、竞品声量、互动数据。
计算核心指标SOV、SOE、NSR、同比、环比。
筛选重点帖子高互动、负面、话题相关内容。
生成 AI 洞察品牌表现、话题总结、情感观点。
渲染 HTML 报告生成报告并人工复核。

人工周报流程

一份周报从需求确认到报告交付，通常需要经过范围确认、数据获取、指标计算、内容筛选、洞察生成和报告复核。

02 指标口径与配置范围

指标口径与统计范围需要保持一致

周报中的核心指标用于对比海信与竞品在不同平台、周期和品线下的表现。指标计算依赖统一的品牌范围、竞品范围、平台范围和周期范围，任一维度口径不一致，都会影响最终结论。

因此，工作台在生成报告前需要先完成配置范围确认，确保后续指标计算和 AI 洞察使用同一套统计口径。

SOV本品声量 /（本品声量 + 竞品声量）用于判断品牌在整体讨论中的声量份额。
SOE本品互动量 /（本品互动量 + 竞品互动量）用于判断品牌在互动表现中的占比。
NSR（正面声量 - 负面声量）/ 总声量用于判断品牌口碑的正负向净表现。

统计口径

同一份报告内，品牌、竞品、平台、周期和关键词范围需保持一致。

品牌范围本品品牌和竞品品牌必须先确定
平台范围抖音、小红书、微博、B站等平台口径一致
周期范围本期、同比期和环比期不能混用
固定公式 / 自定义范围 / 统一分母
03 返工来源分析

返工通常来自前置口径或数据异常

内部工作台保留人工复核环节，同时将分散的报告生产动作整理为固定步骤，使配置、取数、计算、帖子筛选、AI 洞察和 HTML 报告输出可以逐步检查。

  • 报告范围变化后，品牌、竞品、品线和关键词需要重新确认。
  • 平台数据缺失时，相关指标和洞察结论需要重新复核。
  • 重点帖子缺失时，AI 洞察会缺少内容依据。
  • HTML 报告渲染异常时，需要回到对应步骤定位问题。

返工来源

配置、数据、帖子、洞察和报告渲染任一环节出错，都会影响最终报告。

口径不一致品牌、竞品、平台或周期范围不一致。
数据缺失部分平台或关键词组合未召回有效内容。
帖子缺失重点帖子未拉取，洞察缺少内容依据。
洞察偏差AI 结论与指标或帖子内容不一致。
口径 / 数据 / 帖子 / 洞察 / 渲染
04 自动化流程拆解

报告生产流程拆解为 5 个处理模块

内部工作台将人工流程中的主要耗时环节拆分为配置、取数、计算、洞察和渲染五个模块。配置决定报告边界，取数决定数据基础，计算决定指标口径，帖子样本影响洞察质量，渲染决定最终报告产物。

配置模块报告名称、品牌、竞品、周期、关键词和过滤词等输入项。
取数模块拉取品牌声量、平台数据、互动数据和重点帖子。
计算模块计算 SOV、SOE、NSR、趋势、平台分布和品牌对比。
洞察模块整理结构化输入，生成品牌表现、话题总结和情感观点。
渲染模块输出 HTML 报告，并保留人工复核和调整空间。

自动化处理流程

工作台将配置、数据、计算、洞察和输出串成一条可执行流程。

配置确定报告范围和参数
取数读取品牌、平台和帖子数据
计算生成指标和对比结果
洞察组织 AI 输入并生成分析
渲染输出 HTML 报告
配置 → 取数 → 计算 → 洞察 → 渲染
05 生成进度可视化

报告生成进度拆解为 5 个执行节点

内部工作台将报告生成过程拆分为取数、计算、帖子拉取、AI 洞察和报告渲染五个节点，并记录各节点的执行状态、耗时和异常原因。通过节点状态，可以判断生成耗时主要来自数据获取、指标计算、帖子召回、AI 生成还是报告渲染。

  • 每个节点展示待开始、进行中、已完成或失败状态。
  • 每个节点记录执行耗时，用于判断主要耗时环节。
  • 运行日志记录当前正在执行的环节，方便回溯异常。
  • 生成完成后进入报告预览，缩短人工复核路径。

06 交付前报告制作

用内部工作台承接交付前的周报制作

在正式周报配置中心上线前，内部工作台先承接周报生成流程。通过真实品牌、竞品、周期和关键词配置，完成取数、计算、帖子拉取、AI 洞察和 HTML 报告输出，并在每次生成后进行人工复核和必要调整。

  • 使用真实品牌、竞品、周期和关键词配置生成周报。
  • 检查数据结果是否覆盖目标平台和重点帖子。
  • 对照数据库结果复核 SOV、SOE、NSR 等指标口径。
  • 检查 AI 洞察是否引用正确的指标和帖子依据。
  • 根据交付中暴露的问题调整配置项、Prompt 输入结构和异常提示。

试跑检查项

试跑重点集中在配置完整性、数据召回、指标口径和报告输出质量。

配置检查品牌、竞品、周期和关键词是否完整
数据检查目标平台和重点帖子是否正常召回
输出检查AI 洞察和 HTML 报告是否可复核
